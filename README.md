# 2026 Shared Visualizations

Standalone HTML visualizations, served at <https://neurostuff.github.io/2026_shared_visualizations/>.

| Visualization | Description |
| --- | --- |
| [Neurostore Pipeline Atlas](https://neurostuff.github.io/2026_shared_visualizations/visualizations/neurostore-pipeline-atlas.html) | Interactive map of the Neurostore ingestion and meta-analysis pipeline. |

## Adding a visualization

1. Put a self-contained `.html` file in `visualizations/` (lowercase, hyphenated name).
2. Add a row to the table above linking to `https://neurostuff.github.io/2026_shared_visualizations/visualizations/<name>.html`.
3. Commit and push to `main`; GitHub Pages republishes in a minute or two.
